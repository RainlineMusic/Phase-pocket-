# Исправление пропущенных пиков — 0.1.1

16.10.2026. Проверка на предоставленном стерео WAV, 48 kHz, 10.9714 s.
Аудиофайл не включён в репозиторий. Замеры выполнены offline;
настройки пользователя в исходном сообщении не указаны, поэтому ниже
явно приведены использованные настройки.

## Причины

1. Главный пик на 3.27973 s попадал в точный dry-запас у границы 3.28 s.
   На сетке 80 ms никакой угол не мог изменить этот пик. Участки теперь
   имеют длину 40–120 ms, с границами в областях меньшей энергии.
2. Смешивание сухой и повёрнутой фаз взаимно ослабляло сигнал на переходах.
   Теперь sin²-окно меняет непосредственно угол. Конечный float-результат
   целиком проверяется, включая переходы и контекст true-peak.
3. 20-ms Hilbert FIR заметно ослаблял квадратурную ветвь в басу:
   на 50 Hz её модуль около 0.717. При полной поддержке 80 ms — около 1.
   На 20 Hz модуль остаётся около 0.924: фильтр всё ещё конечный.
4. Максимальная ошибка каждой узкой FFT-полосы короткого прямоугольного
   фрагмента давала ложный veto при переносе энергии фазой. Спектральная
   проверка теперь включает контекст, объединяет частоты ниже 120 Hz и
   ограничивает энергетически взвешенную RMS log-ошибку (0.6 dB), а также
   изменение отдельной активной полосы (3 dB) при Tolerance=0.10 dB.
   Проверка появления энергии в пустых полосах сохранена. Это изменение
   метрики и её калибровки, а не сохранение прежнего спектрального допуска.

RMS/энергия L/R/M/S по-прежнему ограничены 0.10 dB. Сохранены проверки
корреляции, центроида и локальной энергии атаки. Ветка без обработки,
точные dry-запасы, проверка итогового TP и минимум улучшения 0.2 dB сохранены.

## Повторные проверки

- Portable DSP: no-op/bypass/reset при 44.1/48/96/192 kHz, точное совпадение.
- 9/12 harmonic fixtures принимаются, для принятых проверен достижимый Strict.
- Событие у бывшей 80-ms границы и смещения −48/0/+48/+503 samples:
  все обработаны, без Late; снижение sample peak около 1.77 dB.
- Независимый 16x замер: отдельный burst −0.867743 → −2.855954 dBTP;
  поток −1.284297 → −3.060282; граничное событие −1.287772 → −3.059431.
- Повтор после reset даёт те же samples; L=R, L=−R и пустой канал сохранены.
- В RT callback 0 heap allocations; при просроченном плане весь участок dry.
- Предоставленный WAV прогнан также с realtime callback по 192 samples
  с темпом 48 kHz: 18 accepted / 19 skipped / 0 late при −6 dBTP Partial;
  выход побитово совпадает с offline на этой машине.
- ASan/UBSan проходят; LeakSanitizer отключён из-за ограничения /proc.
- Linux VST3/Standalone собираются; JUCE processor/editor и CTest проходят.

Фиксированная PDC увеличена с 224.67 до 324.67 ms при 48 kHz из-за более
точного FIR и максимального адаптивного окна. Хост получает новое значение.
Параметры и сохранённые состояния совместимы; дизайн сохранён.

Это измерительная проверка на одном музыкальном файле и синтетике,
не ABX и не доказательство прозрачности на любом материале. Алгоритм
не копирует внутренний Adaptive Phase Rotation RX.
