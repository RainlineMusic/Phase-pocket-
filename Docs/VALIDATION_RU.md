# Проверки Phase Pocket 0.1.0

16.10.2026. Локальная среда: Linux x86_64, GCC 13.3, JUCE 8.0.6.
Этот документ фиксирует тесты прототипа, не пригодность к коммерческому релизу.

## Что проверено

- Локальная CMake-сборка VST3 и standalone, загрузка JUCE processor/editor.
- DSP no-op, неизменённый задержанный bypass и отсутствие старого сигнала
  после reset на 44.1 / 48 / 96 / 192 kHz; сравнение float samples точное.
- Синтетические harmonic bursts: 7/12 вариантов приняты в Partial;
  для каждого принятого варианта отдельно проверен Strict с достижимым
  порогом. Диапазон снижения пика этих вариантов примерно 0.21–1.81 dB.
- Неподходящие DC и Nyquist-сигналы отклоняются, нет ложного принятия.
- Поток из трёх соседних 80-ms участков: 3 accepted, 0 skipped, 0 late
  в offline; повтор после reset воспроизводит те же samples.
- Инварианты L=R, L=−R и отсутствие сигнала в правом канале.
- Realtime вызов без ожидания worker: exact dry при Late. Проверка
  thread-local счётчиком `operator new`: 0 выделений в аудиопотоке.
  Вызов намеренно быстрее реального времени, чтобы проверить опоздания.
- AddressSanitizer + UndefinedBehaviorSanitizer: тесты прошли.
  LeakSanitizer отключён из-за ограничений доступа к /proc в этой среде;
  отдельного утверждения об отсутствии утечек нет.
- JUCE processor: блоки 1/16/64/127/512/4096, PDC, state round-trip,
  sample-position seek с очисткой старого delay, создание/закрытие editor.
- CTest: PhaseDSP и PhaseIntegration проходят.
- XML `.jucer` и все указанные в нём исходники/assets валидны.
  Сборка экспортированных Xcode/Visual Studio проектов не выполнялась.
- Реальные снимки трёх тем при ширине 560/800/1200 и BYPASSED:
  `Previews/`. Сигнал в снимках — синтетические harmonic bursts через
  DSP, а не музыкальный трек. Визуальный review отражён в UI_REVIEW.md.

## Независимый замер пиков

SciPy `resample_poly`, 16x, Kaiser β=12; коэффициенты интерполяции плагина
не используются. Для воспроизведения: запустить PhaseDSPTests, затем
Tools/independent_peak_check.py из того же рабочего каталога.

| Сигнал | Dry peak | Output peak | Снижение | ΔRMS |
|---|---:|---:|---:|---:|
| Отдельный harmonic burst | −1.552376 dBTP | −1.763393 dBTP | 0.211017 dB | −0.000037 dB |
| Три потоковых события | −1.284297 dBTP | −3.060358 dBTP | 1.776060 dB | −0.000050 dB |

## Что остаётся

- Уровненные A/B и ABX на разнообразной музыке, оценка слышимости переходов.
- Native macOS/Windows builds, AU/CLAP/AAX и реальный pluginval через
  приложенный workflow. Workflow YAML проверен, удалённый запуск не выполнялся.
- Pro Tools/Ableton/Reaper и другие DAW: long sessions, несколько instances,
  native OpenGL/Direct2D, автоматизация всех параметров, stop/loop/seek.
- Продуктовая серверная активация Phase Pocket и её Online/Offline цепочка.
- Динамическое объединение событий через границы фиксированных 80-ms участков.

Численные проверки и примеры не доказывают неслышимость либо универсальное
улучшение. При неподходящем сигнале и в случае опоздания расчёта output
сохраняет исходный пик, в том числе выше Threshold.
