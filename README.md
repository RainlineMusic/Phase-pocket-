# Phase Pocket 0.1.1

JUCE prototype of a selective stereo phase peak optimizer for Rainline Music.
Based on Duck Pocket feature/duck-license-sidechain.

See [README_RU.md](README_RU.md) for build instructions, controls, DSP,
licensing configuration and prototype limitations.

Open `PhasePocket.jucer` in Projucer or build with CMake.

0.1.1 fixes phase transitions, low-frequency quadrature and peak events at
window boundaries. See [DSP regression notes](Docs/DSP_FIX_0_1_1_RU.md).
