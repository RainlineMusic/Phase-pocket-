# Phase Pocket interface

Operate mode. Inherit Duck Pocket feature/duck-license-sidechain at commit
a22697d61485cda9d4a3fcca868e3fb01d03a059, with the same PocketTokens in
Source/UIStyle.h, embedded Inter fonts, designer dial body rasters and cached
ring styling. No replacement visual world.

Reference size 800 × 700, minimum 560 × 490, fixed 8:7 aspect ratio.
Header 0–56, recessed plot 57–359, controls 363–650, status 653–700.
One graph: −12 to 0 dBFS with input/output fills, a conditional threshold,
and an event peak-savings trace. The graph is above the dials as requested.
Large Threshold and Max Phase flank compact Transition and Tolerance.

Tokens are authoritative in UIStyle.h: Solid Dark chassis #151d25,
raised #263341, glass #14191f, ink #d9e3ee, muted #adb9c7,
key #ccb078, output #a9cbee. Neon and Amber are inherited unchanged.

Bypass retains the blurred background and BYPASSED label; activation retains
the inherited online/offline card. OpenGL is off by default, unavailable on
Windows as in the reference fallback. Long graphs have a 30 FPS budget and
short graphs 60 FPS; plots use bounded time buckets and cached chrome.
